# 决策与被否决的方向

这里记录 Nova 在测试架构治理中定下的决策,以及被明确否决的提议。格式沿用 05 模块的"拒绝建议归档范式":
内容、理由、防重复指引。新项目可以作出不同决策,但应该**有意识地**作出,而不是在不知道这些取舍的情况下
重新走一遍弯路。

## D-01 测试按 L0-L3 四层管理,与"在哪跑"的轴分开

- **决策**:每个检查必须能回答"属于哪一层"和"在哪一档跑"。
- **理由**:两条轴混在一起时,"两层防护"之类的说法会让人以为预检和全量是在守不同的东西,其实它们只是
  执行时机不同。
- **防重复指引**:看到"再加一层测试"的提议,先问它补的是哪一层的哪个缺口。

## D-02 发布前必须有 L0 doctor,且前置条件是唯一真源

- **决策**:任何昂贵链路(预发布发布、生产发布、全量测试)启动前先跑 doctor;发布脚本里的失败点必须
  标注由哪个 doctor 检查覆盖,或者明确标成"只能运行时观察"并写理由。
- **理由**:没有前置条件模型,串行发现是必然的。
- **防重复指引**:新增发布步骤时,同一批改动里登记它的前置条件。

## D-03 L2 守卫的准入规则

- **决策**:新 L2 守卫必须满足三条:①守的是类级不变量,不是快照;②有反向测试(刻意违规会变红);
  ③写明属于哪一档执行、由哪个入口调用。
- **理由**:L2 是腐烂最快的一层;不设准入,"出一个事故加一个守卫"会让守卫成为假红的主要来源。
- **防重复指引**:提议"加一个测试钉住这个列表/这个数字"时,改写成遍历 + 属性判断,或者改成生成器 + 新鲜度检查。

## D-04 固定点类失败自动重新生成并重试一次

- **决策**:失败只因生成物过期时,收尾流程自动重新生成并重试一次,仍红才算真红。
- **理由**:这类失败没有任何信息量,却是收尾返工的主要来源之一。

## D-05 超时不靠调大数字解决

- **决策**:全量门禁目标 ≤10 分钟;单任务硬顶 15 分钟;超了就拆分或挪到云端并行,不抬超时值、不加名字豁免。
- **理由**:调大超时只会让下一次超时更晚被发现。
- **防重复指引**:提议"把超时从 X 调到 Y"时,先给出拆分方案。

## D-06 开发环境保持轻量(否决:让开发环境走完整发布链路)

- **被否决的提议**:让开发环境也跑与预发布相同的完整发布链路和全量测试,以便提前发现预发布问题。
- **理由**:代价是每次开发发布多出分钟级耗时,而预发布特有的问题来自环境与代码路径分叉,不是开发环境太轻。
- **替代做法**:提交时的秒级精准测试;开发/预发布共用同一套函数、用参数控制轻重;预发布前的 doctor 体检。
- **防重复指引**:任何会增加开发发布/测试分钟级耗时的提议,视为已否决。

## D-07 不新增"跳过全仓检查"的小改动快车道(否决)

- **被否决的提议**:给小 bugfix 开第三档,跳过与 diff 无关的全仓检查。
- **理由**:实测与 diff 无关的检查合计只有 6-9 秒;墙钟大头是按 diff 触发的重检查,跳过它们等于跳过对
  改动本身的验证。真正的返工来自误报、错误指引和被别人的红灯连累,应该逐项修这些。
- **重新评估前提**:某项检查同时满足"成本显著"和"单模块小 diff 在结构上不可能改变其判定"。

## D-08 跳过预检用文本审批,不用一次性 token(否决 token 方案)

- **被否决的提议**:用一次性 token 替代自由文本审批,防止 AI 自我批准。
- **理由**:决策者认为文本 + 审计日志 + 提交尾注已经足够可追溯,token 增加的流程摩擦不值得。
- **已知风险(已接受)**:AI 可以写一段听起来像已授权的文字;靠定期审计跳过记录兜底。

## D-09 一直不绿、又自动触发的门禁降级为手动派发

- **决策**:生产发布门禁改为只在发布入口按精确提交派发,不再由推送自动触发。
- **理由**:自动触发 274 次 0 次绿,空跑占当月 CI 账单 57%,而且没有任何人因为它的红而停下。

## D-10 熔断:同一子系统连续两轮全链重放就停

- **决策**:同一问题连修 3 次不过就停下报告;同一子系统连续 2 轮"失败 → 单点修 → 全链重放"立刻换策略。
- **理由**:串行链路的成本是轮数 × 单轮时长,熔断直接截断轮数。

## D-11 治理类任务有终点

- **决策**:覆盖率 / 审计类任务在主要目标达成(从 advisory 翻成 strict、首轮完整报告交付)后降级为按需;
  并行 worker 数按剩余额度节流,不按"可拆单元数"。
- **理由**:这类任务天然没有终点;额度是共享池。
