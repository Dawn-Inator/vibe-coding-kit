定义 / THE CONTRACT03 / 08

把意图写成
可检查的约定

先说清场景、边界与验收标准，再开始实现。

需求示例 / 邮箱验证码登录
成员通过邮箱验证码登录
场景成员使用邮箱接收验证码，完成登录。
边界覆盖登录与失败提示；注册流程不在本次范围。
验收标准有效码可登录；过期或错误码被拒绝并提示；连点不重复触发登录。
